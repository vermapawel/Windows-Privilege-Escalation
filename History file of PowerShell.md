**History file of PowerShell**

***type C:\Users\thm-unpriv\AppData\Roaming\Microsoft\Windows\PowerShell\PSReadLine\ConsoleHost_history.txt***

CMD can only save commands of the current session. It does not create a history file of command from previous sessions.

However PowerShell keeps a history file of commands from previous sessions as well.

This history file is user specific.
